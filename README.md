# ☕ Java Programming Portfolio

A curated collection of Java programs demonstrating core programming paradigms, pattern problems, the pillars of OOPs, and concurrent programming. Developed with a focus on code efficiency, clean architecture, and robust logic.

---

## 🛠️ Tech Stack & Features
* **Language:** Java (JDK 17+)
* **Paradigm:** Object-Oriented Programming (OOP) & Multithreading
* **Optimization:** Focused on efficient Time & Space complexity
* **Styling:** Features clean, structured terminal outputs and interactive GUIs

| Category | Description | Key Implementations |
